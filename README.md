# 台股每日分析報告

## 分析方法論

本系統每個交易日晚間 10 點自動執行，蒐集當日市場資料，生成標準化報告，存於 `reports/` 目錄。

---

### 1. 大盤分析
- 台股加權指數（TAIEX）收盤點位、漲跌幅、成交量
- 大盤情緒判定：漲幅 > +1% 為多、< -1% 為空、其他為中性

### 2. 外資籌碼分析（核心指標）
外資是台股最重要的多空風向球：
- **外資連買天數**：連買 3 天以上為強烈多方訊號
- **外資持股比例**：持股 > 60% 的個股，每張買賣超都有顯著股價影響
- **當日買超/賣超排行**：反映資金輪動方向

### 3. 個股勝率評估（0–100分）
| 維度 | 權重 | 說明 |
|------|------|------|
| 外資趨勢方向 | 30分 | 連買/連賣天數與方向 |
| 外資持股走向 | 20分 | 持股比例增加/減少 |
| 目標價上漲空間 | 25分 | 外資目標價 vs 現價 |
| 基本面支撐 | 15分 | EPS成長、本益比合理性 |
| 風險因子（扣分） | -10分 | 技術面、融資、散戶情緒 |

**勝率解讀：** 70+積極布局 / 60–70等訊號 / 50–60觀望 / <50不建議

### 4. 長線 vs 短線邏輯
- **長線（6–18個月）**：P/E合理 + 外資持續累積 + EPS持續成長 + 距52週低點近
- **短線（1–4週）**：外資連買3日以上 + 量價配合 + 未在52週高點附近

### 5. 融資/散戶情緒（反向指標）
- 融資餘額持續上升 → 散戶追高 → 風險訊號
- 新聞大量報導散戶搶進 → 往往是短線高點而非底部
